╔══════════════════════════════════════════════════════════════════════════════════════════════════════╗
║ SEARCH WORKFLOW                                                                                       ║
╚══════════════════════════════════════════════════════════════════════════════════════════════════════╝

1. Click [Advanced Search] button in toolbar
   └─▶ Search panel expands below toolbar

2. Select search mode (Quick / Filter / Cypher / SQL)
   └─▶ Mode-specific UI appears

3. Enter search criteria
   └─▶ Type in input field OR click preset button

4. Execute search
   └─▶ Click [Search] / [Execute] button OR press Enter

5. View results in scrollable table
   └─▶ Each result shows: Label, ID, Properties, Load button

6. Load node into graph
   └─▶ Click [Load] button on desired result
   └─▶ Node appears in graph canvas
   └─▶ Node properties loaded automatically
   └─▶ Connected edges fetched and displayed

7. Interact with loaded node
   └─▶ Double-click to expand edges
   └─▶ Right-click for context menu
   └─▶ Select to view/edit properties
   └─▶ Add new edges or properties

║ EXAMPLE QUERIES                                                                                       ║
╚══════════════════════════════════════════════════════════════════════════════════════════════════════╝

Quick Search:
  Alice
  Person
  Forklift

Filter Search:
  name contains "Alice"
  speed > 100
  status equals "active"
  type equals "Person"

Cypher:
  MATCH (n) RETURN n LIMIT 20
  MATCH (n:Person)-[:KNOWS]->(m) RETURN n, m
  MATCH (n) WHERE n.speed > 100 RETURN n ORDER BY n.speed DESC
  MATCH (n)-[r]->(m) WHERE type(r) = 'REPORTS_TO' RETURN n, r, m

SQL:
  SELECT * FROM nodes LIMIT 20
  SELECT * FROM nodes WHERE type = 'Person'
  SELECT * FROM nodes WHERE name LIKE '%Alice%'
  SELECT n.*, COUNT(e.*) as edge_count
  FROM nodes n
  LEFT JOIN edges e ON n.id = e.source
  GROUP BY n.id
  LIMIT 20
